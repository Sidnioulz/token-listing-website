## What is Token Listing?

In code environments, design tokens are rarely represented in the DTCG format. Every styling system, framework or platform has its own conventions for naming and structuring tokens. The Token Listing format fills that gap: it maps DTCG tokens to their exact representations in code, with a predictable, machine-readable structure. Inline code like `$extensions` and `tokenListing` should sit comfortably in prose.
